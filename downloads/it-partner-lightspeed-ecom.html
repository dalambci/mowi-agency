Lightspeed eCom-koppeling voor Mowi instellen

Eén A4 om door te sturen naar de collega, hostingpartij of IT-partner die de Lightspeed eCom-kant regelt.

Wat er nodig is

De organisatie die u ondersteunt koppelt Mowi aan haar Lightspeed eCom-webshop. Daarvoor zijn drie gegevens nodig: het API-adres van de omgeving (het cluster-adres) en een sleutelpaar uit Lightspeed eCom, een API Key en een API Secret. Mowi gebruikt die sleutel alleen om bestellingen op te zoeken. Er wordt nooit iets in de webshop aangepast.

Waar u de sleutel aanmaakt

  1. Log in op het beheer van de Lightspeed eCom-webshop.
  2. Ga naar Instellingen, dan Winkelinstellingen, dan Developers (Ontwikkelaars).
  3. Klik op New API Key (Nieuwe API-sleutel), geef een naam in, bijvoorbeeld Mowi, en bevestig.
  4. U ziet nu een API Key en een API Secret. Kopieer beide meteen.
  5. Kopieer ook het volledige API-adres van de omgeving. Dat begint met https://api.shoplightspeed.com/ en staat op dezelfde pagina.

Het API-adres verschilt per omgeving (cluster). Zonder het juiste, volledige adres kan Mowi geen verbinding maken.

Welke rechten de sleutel krijgt

Mowi gebruikt de sleutel alleen om bestellingen en klantgegevens op te zoeken. Er wordt nooit iets aangepast of verwijderd. De sleutel staat los van de inloggegevens van de beheerder en kan op elk moment in Lightspeed eCom worden ingetrokken, zonder dat dit een account raakt.

Hoe u de sleutel terugstuurt

Stuur de API Key, de API Secret en het API-adres niet per e-mail in platte tekst. Mowi volgt dit direct met u op en geeft aan via welk kanaal u ze veilig kunt delen.

Wordt de sleutel later in Lightspeed eCom ingetrokken of verwijderd, dan moet de koppeling met een nieuwe sleutel opnieuw ingesteld worden.

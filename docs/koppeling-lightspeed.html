Lightspeed eCom koppelen

Via de Lightspeed eCom-koppeling zoekt uw agent de status van een bestelling rechtstreeks op in uw webshop, bijvoorbeeld als een klant belt of mailt met "waar blijft mijn bestelling?". De koppeling is alleen lezend: Mowi past nooit iets aan in uw webshop.

Na deze stappen is uw webshop gekoppeld aan het dashboard en heeft het dashboard de verbinding getest.

Vereisten
  • Toegang tot het beheer van uw Lightspeed eCom-webshop, of iemand die dat namens u kan doen (bijvoorbeeld uw webbouwer).
  • Toegang tot het dashboard.

Wat zijn de API key, API secret en het API-adres?

Lightspeed geeft Mowi geen toegang met uw eigen inloggegevens. U maakt in Lightspeed zelf een aparte sleutel aan: een API key en een API secret, met precies de rechten die u aanvinkt. Voor deze koppeling is dat alleen Read (lezen) bij Orders en bij Customers. Customers is nodig om bestellingen te vinden op het e-mailadres van een klant. U kunt de sleutel op elk moment zelf uitschakelen in Lightspeed.

Het API-adres hangt af van waar uw webshop draait. Het ingebouwde adres van een Europese webshop eindigt op .webshopapp.com, dat van een Noord-Amerikaanse webshop op .shoplightspeed.com. Het API-adres gebruikt hetzelfde domein, met de taalcode van uw webshop erachter:

  • Europa: https://api.webshopapp.com/nl/
  • Noord-Amerika: https://api.shoplightspeed.com/nl/

Gebruikt uw webshop geen Nederlands? Vervang nl dan door de taalcode van uw webshop, bijvoorbeeld fr of de.

De koppeling inrichten

1

Open Koppelingen in het dashboard

Klik in de zijbalk op Settings en daarna bij Koppelingen op Openen. U komt er ook via het menu onder uw initialen linksboven (Koppeling(en)) of via de setupstap Koppel uw systemen.

U ziet nu de pagina Koppelingen, met tegels onder Mailbox, Webshops en Reserveren & afspraken.

2

Klik op de tegel Lightspeed eCom

Klik onder Webshops op Lightspeed eCom.

Het paneel Lightspeed eCom koppelen klapt open, met de stappen en de velden API-adres, API Key en API Secret.

Het paneel Lightspeed eCom koppelen in het dashboard.

3

Open Developers in Lightspeed

Log in op het beheer van uw Lightspeed eCom-webshop en ga naar Instellingen (Settings) → Shopinstellingen (Store Settings) → Developers.

U ziet nu de pagina Developers, met de knop Nieuwe API-sleutel (New API key).

4

Maak een nieuwe API-sleutel aan

Klik op Nieuwe API-sleutel (New API key), vul als naam bijvoorbeeld "Mowi" in en klik op Opslaan (Save).

U ziet nu de nieuwe sleutel, met onder INSTELLINGEN (SETTINGS) een schakelaar en een lijst met toestemmingen.

Wilt u meer dan één API-sleutel aanmaken, bijvoorbeeld omdat u er al een gebruikt voor een andere koppeling? Dan vraagt Lightspeed u contact op te nemen met hun support.

5

Schakel de sleutel in en geef alleen leesrechten

Zet onder INSTELLINGEN (SETTINGS) de schakelaar aan om de sleutel in te schakelen. Vink bij Orders (bestellingen) en bij Customers (klanten) alleen Read (lezen) aan. Klik op Opslaan (Save).

U ziet nu onder DETAILS uw API key. De API secret is nog verborgen.

6

Toon de API secret

Klik bij de API secret op Weergeven (Show).

U ziet nu de API secret in leesbare tekst.

7

Vul het formulier in en klik op Koppelen

Ga terug naar het dashboard. Vul bij API-adres het API-adres van uw webshop in, voor een Europese webshop https://api.webshopapp.com/nl/. Plak de API key en de API secret in de velden API Key en API Secret. Klik op Koppelen.

Het dashboard test de verbinding meteen en toont de melding Koppeling opgeslagen en getest — de verbinding werkt. De tegel Lightspeed eCom krijgt het label Verbonden.

De koppeling werkt als de tegel Lightspeed eCom Verbonden toont. Open de tegel later opnieuw om te zien wanneer de verbinding voor het laatst getest is, of klik op Test verbinding.

Een koppeling geldt voor elk kanaal van uw agent: aan de telefoon en in de e-mail zoekt hij dezelfde bestellingen op. Heeft u meer dan één webshop? Open de tegel en vul het formulier onder Nog een Lightspeed eCom koppelen in.

Problemen oplossen

"Koppeling opgeslagen, maar de test is nog niet gelukt"

Het dashboard heeft uw gegevens bewaard, maar kon er nog geen bestelling mee ophalen. Open de tegel Lightspeed eCom: onder de status staat wat er misging. Pas de gegevens aan via Sleutel wijzigen en klik op Opslaan. Het dashboard test dan opnieuw.

"De API-sleutel/secret werd geweigerd (401)"

Lightspeed herkent de sleutel niet. Controleer in Lightspeed of de sleutel is ingeschakeld en kopieer de API key en de API secret opnieuw. Controleer ook het domein in het API-adres: een Europese webshop gebruikt api.webshopapp.com, een Noord-Amerikaanse api.shoplightspeed.com. Vul de gegevens in via Sleutel wijzigen in het paneel Lightspeed eCom.

"De API-sleutel mist rechten (403)"

De sleutel staat uit of mag de bestellingen niet lezen. Zet in Lightspeed de schakelaar van de sleutel aan, vink bij Orders en bij Customers de optie Read aan en klik op Opslaan (Save). Klik daarna in het dashboard op Test verbinding.

"De API-sleutel mag geen klanten lezen"

De sleutel mag de bestellingen lezen, maar niet de klanten. Die heeft de agent nodig om bestellingen op e-mailadres te vinden. Vink in Lightspeed bij Customers ook Read aan, klik op Opslaan (Save) en daarna in het dashboard op Test verbinding.

"Geen Lightspeed-omgeving gevonden op dit adres (404)"

Het API-adres klopt niet. Het begint met https://api.webshopapp.com/ of https://api.shoplightspeed.com/ en eindigt op de taalcode van uw webshop, zoals nl/. Pas het adres aan via Sleutel wijzigen.

"De webshop is niet bereikbaar"

Het dashboard kon het API-adres niet bereiken. Controleer het adres op typefouten.

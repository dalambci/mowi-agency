Uw eerste agent instellen (checklist)

Deze checklist is de kortste route van inloggen tot een werkende agent. Elk punt verwijst naar de volledige stapgids voor dat onderdeel.

Na deze checklist weet u welke stappen bij elke agent terugkomen, in welke volgorde u ze doorloopt, en waar u de volledige uitleg per stap vindt.

Vereisten
  • Toegang tot het dashboard (inloggegevens van uw organisatie).
  • Weten welke agent u als eerste wilt instellen (zie de lijst hieronder).
  • Rechten om toegang te verlenen tot het systeem waarmee die agent moet koppelen — of iemand die dat namens u kan doen.

Checklist

  • Log in bij het dashboard. Zie Overzicht: wat is het dashboard.
  • Klik in de zijbalk op Agents en zoek de agent die u wilt instellen.
  • Open de detailpagina van die agent en lees onder About wat de agent doet.
  • Geef Mowi toegang tot het systeem waarmee deze agent moet koppelen (bijvoorbeeld een mailbox, CRM, ERP of Power BI-omgeving). Mowi's implementatieteam richt de koppeling voor u in.
  • Controleer na bevestiging van Mowi of de status op de detailpagina van de agent op Running staat.
  • Bekijk Run history op diezelfde pagina om te zien dat er nieuwe regels verschijnen.

Volledige gidsen per agent

  • CRM sync instellen
  • Email triage instellen
  • Invoice processing instellen
  • Lead enrichment instellen
  • Report generator instellen

Volgende stappen

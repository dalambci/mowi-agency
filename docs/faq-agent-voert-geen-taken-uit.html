Een agent voert geen taken uit

Deze pagina helpt bij elke agent die niets lijkt te doen. Voor bijzonderheden per agent: elke agentpagina heeft ook een eigen sectie Problemen oplossen.

Loop deze volgorde af

1

Log in bij het dashboard

Ga naar het dashboard, vul uw e-mailadres en wachtwoord in en klik op Log in.

U ziet nu het Home-overzicht van het dashboard.

2

Open Agents

Klik in de zijbalk op Agents.

U ziet nu een lijst met alle agents voor uw organisatie.

3

Controleer de status

Klik op de rij met de betreffende agent en bekijk de status rechtsboven.

Staat de status op Paused? Dan draait de agent niet. U kunt dit niet zelf wijzigen — neem contact op met Mowi.

4

Controleer het schema

Bekijk op dezelfde pagina het schema onder de titel.

Agents draaien op een vast schema, niet continu. Wat u als "niets doen" ervaart, kan ook betekenen dat de agent nog niet aan de beurt is geweest — bekijk Runs, last 14 days om te zien hoe vaak de agent al gedraaid heeft.

5

Controleer Run history

Bekijk de tabel Run history onderaan de detailpagina.

Staat de laatste run op Failed? Bekijk de kolom Note voor een foutmelding.

6

Controleer de koppeling

Ga na of het gekoppelde systeem van deze agent (bijvoorbeeld een mailbox, CRM, ERP of Power BI-omgeving) nog actief verbonden is.

Zie Een koppeling werkt niet meer voor de vervolgstappen.

7

Neem contact op met Mowi

Open een supportticket als geen van de vorige stappen iets heeft opgeleverd.

Vermeld de naam van de agent en, indien van toepassing, de tekst uit Note bij de laatste mislukte run — dat scheelt Mowi een vraag terug.

Volgende stappen

Klaar om een ticket te openen? Lees Contact opnemen met support.

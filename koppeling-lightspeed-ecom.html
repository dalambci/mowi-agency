Wat kunt u met AI automatiseren in Lightspeed eCom?

Met de Lightspeed eCom-koppeling leest Mowi uw bestellingen, alleen lezend. Uw Inbox agent en Voice agent zoeken de bestelstatus op zodra een klant ernaar vraagt, op bestelnummer of e-mailadres, inclusief de track-en-tracecode zodra die er is. Koppelen kost 5 stappen met een eigen API-sleutel uit uw webshop. Die sleutel trekt u zelf in, wanneer u wilt.

Wat leest Mowi uit Lightspeed eCom?

Uw bestellingen. Niets anders, en nooit schrijvend.

Bestelling opgezocht

Op bestelnummer of op het e-mailadres van de klant, inclusief de track-en-tracecode zodra die er is.

Alleen lezend

Mowi past nooit iets aan in uw webshop. De sleutel wordt alleen gebruikt om op te zoeken.

Uw eigen sleutel

U koppelt met een eigen API-sleutel uit Lightspeed eCom, niet met uw accountwachtwoord. Die trekt u zelf in.

Status altijd actueel

Rechtstreeks uit uw eigen webshop, dus nooit verouderd of dubbel bijgehouden.

Welke agents gebruiken de Lightspeed eCom-koppeling?

Twee agents en een dashboard, allemaal via dezelfde koppeling.

Inbox agent

Zoekt de bestelling op bij een vraag per e-mail, voordat het conceptantwoord klaarstaat.

Voice agent

Zoekt de bestelling op terwijl de klant aan de lijn is.

Orderstatus

Zoekt bestellingen op in uw webshop. Alleen lezen.

Hoe koppelt u Lightspeed eCom aan Mowi?

In 5 stappen, met een eigen API-sleutel uit uw webshop.

1

Log in op het beheer van uw webshop

Uw Lightspeed eCom-account.

2

Open de Developers-instellingen

Via het menu: Instellingen, Winkelinstellingen, Developers.

3

Maak een nieuwe API-sleutel aan

Klik op New API Key, geef een naam in, bijvoorbeeld Mowi, en bevestig.

4

Kopieer de API Key, API Secret en het API-adres

Alle drie staan op dezelfde pagina. Het API-adres begint met https://api.shoplightspeed.com/.

5

Plak alle drie en klik op Koppelen

Mowi test de verbinding meteen.

Wat heeft uw IT-partner of accountant nodig?

Alleen een eigen API-sleutel uit Lightspeed eCom (API Key en API Secret) met het bijbehorende API-adres, niet uw accountwachtwoord. Die maakt uw IT-partner zelf aan. Open het A4 voor uw IT-partner

Veelgestelde vragen

Is de Lightspeed eCom-koppeling alleen lezend?

Ja. Mowi haalt bestellingen op en past nooit iets aan of verwijdert iets in uw webshop.

Wat zijn een API Key en API Secret?

Een eigen sleutelpaar dat u in Lightspeed eCom aanmaakt, bij Instellingen, Winkelinstellingen, Developers. Lightspeed geeft Mowi nooit toegang met uw accountwachtwoord.

De sleutel werd geweigerd (401). Wat nu?

De sleutel is ongeldig of ingetrokken. Maak in Lightspeed eCom een nieuwe API Key en API Secret aan en vul die opnieuw in bij Sleutel wijzigen.

Geen omgeving gevonden (404). Wat nu?

Controleer het API-adres op typefouten. Dit cluster-adres begint met https://api.shoplightspeed.com/ en staat bij uw Developers-instellingen.
